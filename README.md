Aplicativo web que integra com a API do Proxmox para gerenciamento de VMs clientes

O aplicativo gerencia VMs criando, organizando, contabilizando de forma simplificada
de acordo com os dados obtidos pela API do Proxmox

A interface é simples voltada para operadores N1 para disponibilizar rapidamente
ambientes para os clientes, de forma rápida e objetiva

As VMs criadas por aqui devem receber tags e só elas ficam visíveis (tag de VMs cliente). 
Também pode ter tags que deixam certas VMs invisíveis (tags de VMs mgmt por exemplo)
